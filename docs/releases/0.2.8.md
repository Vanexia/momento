# Momento 0.2.8

This release fixes errors when deleting, renaming, and exporting recordings.

## Fixes

- If Windows refuses to delete a video, Momento keeps its bookmarks,
  thumbnail, and ownership file. This can happen when another player holds
  the video open.
- After a partly successful bulk delete, the status message names the video
  that was deleted and reports the correct count. A leftover thumbnail or
  bookmark file no longer makes a deleted video count as a failed deletion.
- Before renaming a recording, Momento checks for conflicting destination
  files, including old bookmarks and thumbnails. If a later file move fails,
  it attempts to restore the original names and reports any restoration
  failure so you can recover the files.
- Delete and rename check again whether a file is busy after you close the
  confirmation or naming dialog. A repair or export that starts while the
  dialog is open now blocks the operation.
- An unavailable or unwritable clip folder produces an error message instead
  of an unhandled exception in the editor.

The build environment now pins pip 26.2.1 to address
[CVE-2026-13346](https://github.com/advisories/GHSA-qwm4-qh6w-59xr).
pip is a development/build tool and is excluded from the installed app.

## Install or update

Download **MomentoSetup-0.2.8.exe** to install or upgrade. The installer
preserves your settings, recordings, and YouTube setup.

If you already use Momento, a startup check downloads and installs this update
when the app is idle. **Check for updates** downloads it and offers **Install
now** or **Later**. Choose **Later** to install on the next Momento launch.

The installer is unsigned, so Windows may show an Unknown Publisher or
SmartScreen warning. Download it from this repository. Comparing its hash with
`SHA256SUMS-0.2.8.txt` is an optional check for a manual download; the in-app
updater verifies the signed metadata and installer checksum itself.

Release assets include the installer, corresponding Momento and third-party
source archives, the FFmpeg helper, `Momento-update.json`,
`Momento-update.json.sig`, and `SHA256SUMS-0.2.8.txt`.
