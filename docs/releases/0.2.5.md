# Momento 0.2.5

Momento 0.2.5 makes YouTube upload usable in the public installer without
shipping a maintainer-owned Google identity.

## What changed

- YouTube controls are present in every public build.
- Settings now includes an in-app guide for creating a personal Google Cloud
  project and importing a Desktop OAuth JSON file.
- Imported OAuth client details and account tokens are stored separately with
  Windows DPAPI encryption. They are never included in release assets.
- Replacing or removing an OAuth client safely disconnects the previous
  YouTube account.
- Public builds include the Google upload runtime but ignore any bundled OAuth
  file, even if one is added accidentally.
- Diagnostic logs redact local paths, media names, and audio endpoint IDs.
- Custom thumbnails are bounded to 2 MiB and validated as JPEG or PNG before
  upload.
- Release tooling stops before extracting a PyAV wheel whose hash does not
  match the reviewed input.
- Privacy documentation now describes the startup GitHub update request and
  optional Google traffic accurately.

## YouTube setup

Open **Settings > YouTube > Open setup guide**. Each user creates a Desktop
OAuth client in a Google Cloud project they control, imports the downloaded
JSON, and then connects their YouTube account through Google's browser flow.

Google restricts uploads from unverified API projects created after 28 July
2020 to Private visibility until the project passes an API audit. Testing-mode
authorisation can also expire after seven days. Momento explains both limits
before setup.

## Download

Download `MomentoSetup-0.2.5.exe`. The installer upgrades an existing per-user
installation and preserves settings, recordings, and local YouTube setup by
default.

The installer is not code-signed. Windows can show **Unknown Publisher** or a
SmartScreen warning. Compare the installer hash with
`SHA256SUMS-0.2.5.txt` before running it.

Release assets:

- `MomentoSetup-0.2.5.exe`: per-user Windows installer
- `Momento-0.2.5-source.zip`: exact source for this release
- `Momento-0.2.5-third-party-source.zip`: corresponding native source
- `Momento-update.json`: signed update metadata
- `Momento-update.json.sig`: detached Ed25519 signature
- `SHA256SUMS-0.2.5.txt`: SHA-256 values for every published asset
