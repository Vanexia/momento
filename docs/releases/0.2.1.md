# Momento 0.2.1

Momento's first public Windows preview is ready for everyday game recording and clip export.

## Download

Download `MomentoSetup-0.2.1.exe` from this release.

The installer is not code-signed. Windows may display an **Unknown Publisher** or SmartScreen warning. Confirm that the download came from the official Momento repository, select **More info**, then **Run anyway**.

## Highlights

- Automatic recording when a configured game starts
- Game-window capture through Windows Graphics Capture
- Microphone and selected playback-device audio
- In-game bookmarks with a configurable hotkey
- Recording library, playback, search, repair, and storage controls
- Fast MP4 clip export without re-encoding
- Local recordings with no Momento account or telemetry

## Reliability

- Encoder checks use the requested recording profile before capture starts
- Compatible encoder fallback covers NVIDIA, AMD, Intel, Media Foundation, and CPU encoding
- Failed encoders are avoided during later recording attempts
- Momento warns when it reaches CPU encoding
- Recovery and repair handle interrupted recordings when enough MKV data survives

## Requirements And Hardware Status

- 64-bit Windows 10 version 1903 or newer, or Windows 11
- About 615 MB installed, plus space for recordings
- Hardware H.264 encoding recommended

NVIDIA NVENC has passed physical hardware testing. AMD AMF, Intel QuickSync, Media Foundation, and CPU fallback have automated coverage but still need broader testing across real machines and drivers.

## Known Limitations

- The installer is unsigned
- System audio records the selected playback device's complete mix
- Clip boundaries are keyframe-accurate
- No replay buffer, streaming, webcam, HDR, or automatic updates
- The standard public build does not include YouTube upload controls
