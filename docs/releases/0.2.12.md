# Mementos 0.2.12

This release also includes the unreleased 0.2.10 and 0.2.11 changes, listed
at the end.

## Recording

**Game audio and microphone now line up independently.** Each audio source is
placed at the time it was actually captured. Previously, game audio followed
the microphone's timing: it started late by the time the microphone took to
open, and with no microphone configured it started at the very beginning of
the file regardless of when capture began. Short capture gaps are now filled
with silence instead of pulling later audio early.

**The frame-loss warning only appears for sustained loss.** It now judges a
full minute of video and ignores the first minute after a game starts. A
single loading-screen or alt-tab hitch could previously trigger it on
recordings that lost almost nothing.

**Quitting no longer cuts off a recording that is still saving.** If you quit
within a few seconds of closing a game, or Windows signs out, Mementos waits
for the file to finish saving instead of leaving it for repair.

## Settings and files

**A settings file that can't be loaded is never overwritten.** If
`config.json` is temporarily locked at startup (for example by antivirus or
OneDrive), Mementos retries before giving up. If it still can't be read, or
is damaged, Mementos runs on default settings, shows a notice, and leaves
your file untouched. Files saved with a byte-order mark or in the Windows
ANSI encoding now load.

**Moving recordings to a new folder can't leave duplicates.** A file that
another program held open used to be copied in full and then left in both
places. It now stays where it is and is reported as not moved. The preview is
released before the move so the selected recording isn't left behind.

## YouTube uploads

**Cancel stops the upload immediately.** Previously the chunk already being
sent kept going for up to several minutes, so a cancelled upload could still
finish. If the final part had already reached YouTube when you cancelled, the
dialog now says the video was uploaded and links to it.

**Pressing Esc asks before cancelling.** Esc used to hide the progress window
while the upload carried on unseen.

**Network error messages no longer include the private upload address.**

## Updates

If you're on the latest version and its update information is more than 180
days old, the update check now reports that you're up to date instead of
failing. Future releases can be re-signed without breaking update checks.

## From 0.2.11

- The microphone test uses the same gain as recording, and adjusting the volume
  updates a running test.
- The microphone meter uses a logarithmic scale, so quiet input is visible and
  no longer reported as "No input detected".

## From 0.2.10

- The setup folder picker lists available drives.
- Setup checks the recordings folder and bookmark shortcut before advancing and
  again before saving. Cancelling setup leaves saved settings unchanged.
- Audio tests stop when you leave the audio page, change devices, or close
  setup. The review page shows the chosen devices and capture settings.

## Install or upgrade

Download **[MementosSetup-0.2.12.exe](https://github.com/Vanexia/momento/releases/download/v0.2.12/MementosSetup-0.2.12.exe)**
from the official release. The per-user installer keeps your settings and
recordings. Windows may show **Unknown Publisher** because the installer is
not code-signed.

Release assets:

- `MementosSetup-0.2.12.exe`: per-user installer
- `Mementos-0.2.12-source.zip`: application source
- `Mementos-0.2.12-third-party-source.zip`: corresponding native source
- `Mementos-ffmpeg-helper-8.1.2-1.zip`: reviewed standalone helper
- `Mementos-update.json` and `Mementos-update.json.sig`: signed update metadata
- `MomentoSetup-0.2.12.exe`, `Momento-update.json`, and
  `Momento-update.json.sig`: compatibility assets for earlier installations
- `SHA256SUMS-0.2.12.txt`: checksums for the release assets
