# Momento 0.2.6

Momento 0.2.6 stops Steam storefront trailers and launcher windows from
triggering automatic game recording.

## What changed

- Fullscreen Steam store videos rendered by `steamwebhelper.exe` no longer
  count as games.
- Storefront browser helpers, launcher shells, and Windows gaming overlays no
  longer trigger the optional fullscreen fallback.
- Momento removes login screens, patchers, lobbies, and anti-cheat bootstraps
  from the built-in game list. It continues to watch each title's gameplay
  executable.
- Existing settings drop old launcher-only entries when Momento loads them.
- Unknown fullscreen games still work when **Record fullscreen apps not in the
  game list** is enabled.

## Download

Download `MomentoSetup-0.2.6.exe`. The installer upgrades an existing per-user
installation and preserves settings, recordings, and local YouTube setup by
default.

The installer is not code-signed. Windows can show **Unknown Publisher** or a
SmartScreen warning. Compare the installer hash with
`SHA256SUMS-0.2.6.txt` before running it.

Release assets:

- `MomentoSetup-0.2.6.exe`: per-user Windows installer
- `Momento-0.2.6-source.zip`: exact source for this release
- `Momento-0.2.6-third-party-source.zip`: corresponding native source
- `Momento-update.json`: signed update metadata
- `Momento-update.json.sig`: detached Ed25519 signature
- `SHA256SUMS-0.2.6.txt`: SHA-256 values for every published asset
