# Mementos 0.2.11

Local build; publication pending.

When you test your microphone, you now hear the same microphone gain used for
recording. Adjusting the volume slider updates the test while it runs.

The microphone meter now shows peaks on a logarithmic scale, so you can see
quiet input and judge how close louder sounds are to clipping. Setup and
Settings recognise quiet signals that previously triggered "No input detected".

Compatibility assets include `Momento-update.json`, `Momento-update.json.sig`,
and a byte-identical legacy installer alongside the Mementos assets.

- `MementosSetup-0.2.11.exe`
- `Mementos-0.2.11-source.zip`
- `Mementos-0.2.11-third-party-source.zip`
- `SHA256SUMS-0.2.11.txt`
