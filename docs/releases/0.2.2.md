# Momento 0.2.2

Momento 0.2.2 is the release-candidate build for the first wider friend test.
It focuses on recording reliability, storage safety, signed updates, and a
smaller reproducible Windows package.

## Download

Download `MomentoSetup-0.2.2.exe` from this release. The installer runs per user
and does not need administrator access or a separate Python installation.

The installer is unsigned. Windows may show Unknown Publisher or a SmartScreen
warning. Verify the SHA-256 file attached to the release before running it.

## Reliability

- Momento now distinguishes disk and output failures from GPU encoder failures,
  so a full or unwritable drive cannot trigger the wrong encoder fallback.
- Recording startup checks free space immediately and during the session. It
  reports sustained frame loss once instead of allowing a damaged recording to
  continue without a visible warning.
- Microphone capture now fails visibly when a device stays open but stops
  delivering samples.
- Window recreation, capture termination, pending startup, and shutdown paths
  now retry or finalize without publishing a half-started recording.
- Media Foundation hardware qualification requests hardware encoding rather
  than accepting a software implementation under the hardware label.
- The Windows Graphics Capture interval follows the selected frame rate up to
  240 fps.

## Library Safety

- Storage quotas delete only recordings and clips with a verified Momento
  ownership marker. Legacy recordings migrate only after Momento metadata is
  found inside the file.
- Marker files follow rename and folder migration, and they are removed with
  their media and sidecars.
- Active recordings, trims, and repairs share one activity registry. Cleanup,
  migration, trim, and repair cannot race each other over the same file.
- Bookmark saves roll back in memory when their atomic sidecar write fails.

## Interface

- Capture settings fit more Windows display scales and wrap controls before
  they collide.
- Game toggles support keyboard operation and show a visible focus state.
- Setup copy now states the local-only privacy model and the minimum free-space
  requirement more clearly.
- Low-disk, output, audio-stall, and sustained-performance failures appear as
  tray warnings with the relevant next action.

## Updates

- Installed builds check the latest stable GitHub Release once when Momento
  starts. Users can also check from the tray menu or the editor's Help menu.
- Momento verifies Ed25519-signed metadata plus the installer's size and
  SHA-256 before staging an update.
- Recording, finalization, repair, trimming, upload, and visible editor work
  defer installation until the next launch. The updater never interrupts an
  active recording or media task.
- Failed installers use bounded retries and quarantine. A newer signed release
  can replace a quarantined download. Source runs do not contact the updater.

## Packaging

- Momento now ships a reproducible, minimal FFmpeg 8.1.2 helper. The two helper
  executables total about 12 MB and import only Windows system DLLs.
- Live recording now uses Momento's reproducible PyAV 17.0.1 wheel with a
  purpose-built FFmpeg 8.0.1 runtime. Its native DLL payload is 13,058,674
  bytes, down from 67,351,552 bytes in the general-purpose baseline, an 80.6%
  reduction. H.264/AAC recording and all five encoder paths remain available.
- Unused Qt translation catalogs and six image plugins are omitted, removing a
  further 7.88 MiB without changing playback, recording, or supported artwork.
- The release environment is rebuilt from exact pins. Packaging fails on an
  undeclared package, missing licence evidence, mismatched helper, private
  runtime file, or incomplete source bundle.
- The release includes separate, hash-verified Momento and third-party source
  archives covering PyAV, PyQt, Qt, FFmpeg, and native dependencies. Keeping
  the large source archive separate avoids inflating every installer.
- Upgrade removes stale bundled files. Uninstall preserves recordings and user
  data unless the user asks to purge Momento's AppData state.

## Requirements And Limits

- 64-bit Windows 10 version 1903 or newer, or Windows 11
- NVIDIA NVENC has passed physical testing. AMD AMF, Intel QuickSync, Media
  Foundation, and CPU fallback have automated coverage and need wider testing
  on real hardware and drivers.
- System audio captures the selected Windows playback mix, not isolated game
  audio.
- Clip boundaries remain keyframe-accurate because export stream-copies instead
  of re-encoding.
- The standard public build has no telemetry, Momento account, cloud library,
  or YouTube OAuth identity. Its launch-only updater contacts GitHub Releases
  for signed release metadata.
