# Momento 0.2.4

Momento 0.2.4 is a focused polish release for the first wider friend test.

## Improvements

- Update results now sit at the exact centre of the visible Momento window,
  including native title-bar offsets on maximised and display-scaled Windows
  desktops.
- The Windows CI dependency step now invokes the pinned installer through the
  active Python interpreter, avoiding a Windows self-update failure before the
  test suite could start.

## Download

Download `MomentoSetup-0.2.4.exe`. The per-user installer upgrades an existing
Momento installation without removing settings or recordings and does not
require administrator access or a separate Python installation.

The installer remains unsigned. Windows may show Unknown Publisher or a
SmartScreen warning. `SHA256SUMS-0.2.4.txt` is included for verification.

## Release Assets

- `MomentoSetup-0.2.4.exe`: per-user Windows installer
- `Momento-0.2.4-source.zip`: exact Momento source at the release commit
- `Momento-0.2.4-third-party-source.zip`: matching native corresponding source
- `Momento-ffmpeg-helper-8.1.2-1.zip`: reviewed standalone helper build
- `Momento-update.json`: signed updater metadata
- `Momento-update.json.sig`: detached Ed25519 metadata signature
- `SHA256SUMS-0.2.4.txt`: SHA-256 for every published asset
