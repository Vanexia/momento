# Mementos 0.2.10

Local build; publication pending.

The setup folder picker now lists available drives alongside common folders.
Setup checks the recordings folder and bookmark shortcut before advancing,
and checks them again before saving. Cancelling setup leaves saved settings
unchanged.

Audio tests stop when you leave the audio page, change devices, or close setup.
The review page shows the selected devices, capture settings, and startup
preferences. Existing custom frame rates and bitrates display their actual
values when you reopen the tutorial.

The installer preserves existing settings and recordings. Compatibility
assets include `Momento-update.json`, `Momento-update.json.sig`, and a
byte-identical legacy installer alongside the Mementos assets.

Build outputs:

- `MementosSetup-0.2.10.exe`
- `Mementos-0.2.10-source.zip`
- `Mementos-0.2.10-third-party-source.zip`
- `SHA256SUMS-0.2.10.txt`
