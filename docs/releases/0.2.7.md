# Momento 0.2.7

Momento 0.2.7 makes manual update checks ask before restarting the app. Startup
updates remain automatic.

## What changed

- A normal Momento startup checks the latest stable GitHub Release and installs
  a verified update when recording and other app work are idle.
- **Check for updates** downloads and verifies an available update, then offers
  **Install now** and **Later**.
- **Install now** closes the editor and starts the verified installer. Momento
  still postpones installation if recording, export, repair, upload, or sign-in
  work is active.
- **Later** keeps the verified installer and installs it the next time Momento
  starts.
- This release includes the 0.2.6 fix that prevents Steam storefront trailers,
  launcher browser helpers, overlays, and launcher-only processes from
  triggering game recording.

## Download

Download `MomentoSetup-0.2.7.exe`. The installer upgrades an existing per-user
installation and preserves settings, recordings, and local YouTube setup by
default.

The installer is not code-signed. Windows can show **Unknown Publisher** or a
SmartScreen warning. Compare the installer hash with
`SHA256SUMS-0.2.7.txt` before running it.

Release assets:

- `MomentoSetup-0.2.7.exe`: per-user Windows installer
- `Momento-0.2.7-source.zip`: exact source for this release
- `Momento-0.2.7-third-party-source.zip`: corresponding native source
- `Momento-ffmpeg-helper-8.1.2-1.zip`: reviewed optional FFmpeg helper
- `Momento-update.json`: signed update metadata
- `Momento-update.json.sig`: detached Ed25519 signature
- `SHA256SUMS-0.2.7.txt`: SHA-256 values for every published asset
