# Mementos 0.2.9

Draft release notes. This release has not been published.

## Recording diagnostics

Fixed a queue-accounting race that could count a video frame as dropped even
when the encoder accepted it. The performance notification now describes
recent frame loss and confirms that recording continues. Sustained frame loss
under heavy game or GPU load still triggers the warning.

## Corrected name

The app is now called Mementos. Window titles, tray menus, setup, settings,
YouTube dialogs, icons, installer branding, and documentation use the corrected
name. Source users can launch it with `python -m mementos --show`.

Existing profiles keep their settings, YouTube connection, update trust, and
recording folders. Fresh profiles use `%APPDATA%\Mementos` and
`mementos.log`; existing profiles continue using their established app-data
folder. The internal `momento` Python package and recording ownership markers
remain compatible with older recordings and installations.

The public repository and earlier downloads still use the former Momento name.
The release includes `Mementos-update.json` and
`Mementos-update.json.sig`, plus a byte-identical `MomentoSetup-0.2.9.exe`
installer alias and separately signed `Momento-update.json` /
`Momento-update.json.sig` metadata so older installed versions can verify
and install this release.

## Install or upgrade

Updated OAuthlib to 4.0.0 and urllib3 to 2.8.0 to address four dependency
security advisories. The Google sign-in client flow and signed updater checks
pass with the updated libraries.

After publication, download `MementosSetup-0.2.9.exe` from the official release.
The per-user installer preserves settings and recordings. Windows may show
**Unknown Publisher** because the installer is not code-signed.

Release assets:

- `MementosSetup-0.2.9.exe`: per-user installer
- `Mementos-0.2.9-source.zip`: application source
- `Mementos-0.2.9-third-party-source.zip`: corresponding native source
- `Mementos-ffmpeg-helper-8.1.2-1.zip`: reviewed standalone helper
- `Mementos-update.json` and `Mementos-update.json.sig`: signed update metadata
- `MomentoSetup-0.2.9.exe`, `Momento-update.json`, and
  `Momento-update.json.sig`: compatibility assets for earlier installations
- `SHA256SUMS-0.2.9.txt`: checksums for the release assets
