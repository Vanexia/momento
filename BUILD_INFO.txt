Momento 0.2.5 public release build
=================================

Target: Windows 10/11 x64
Python: CPython 3.12
Application packager: PyInstaller 6.20.0, one-folder mode
Installer: Inno Setup 6.7.3, per-user mode

Momento FFmpeg helper
---------------------

Momento bundles a purpose-built FFmpeg/ffprobe helper for offline metadata,
thumbnail, trim, and repair operations. Live recording uses PyAV's separate
native runtime described below.

  FFmpeg version: 8.1.2-momento-helper-1
  Upstream source: https://ffmpeg.org/releases/ffmpeg-8.1.2.tar.xz
  Source SHA-256: 464beb5e7bf0c311e68b45ae2f04e9cc2af88851abb4082231742a74d97b524c
  Build recipe: scripts/build_ffmpeg_helper.sh
  Build workflow: .github/workflows/build-ffmpeg-helper.yml
  Compiler: GCC 16.2.0, statically linked runtime
  Assembler: NASM 3.02
  SOURCE_DATE_EPOCH: 1781667960
  ffmpeg.exe SHA-256: a53993c4fbfbc3fa9ed201ae03502f053182699b3580c7523dc66d176d0371fc
  ffprobe.exe SHA-256: dd7364cd03d86cb5f91fd028174cb6d5f1b2f3ba2606095676e0596b216a4d4d

The helper disables network access, automatic external-library discovery, and
all codecs, formats, protocols, and filters that Momento does not need. It
imports only Windows system DLLs. Two clean local builds produced identical
executables and an identical downloadable helper archive.

PyAV native recording runtime
-----------------------------

  Python distribution: PyAV 17.0.1
  Wheel: av-17.0.1-cp311-abi3-win_amd64.whl
  Wheel size: 6,636,889 bytes
  Wheel SHA-256: fd605ec4ab782c3829bfb4f11c512d7db3bc230d0f889a28f29aab0fb793bf3b
  Native runtime: FFmpeg 8.0.1
  Runtime contract: build/pyav_runtime.json
  Windows recipe: scripts/build_pyav_runtime.ps1
  Native recipe: scripts/build_pyav_runtime.sh
  Compiler: GCC 16.2.0 (UCRT64); PyAV extension built for CPython 3.12
  SOURCE_DATE_EPOCH: 1767139200
  Native DLL payload: 13,058,674 bytes
  General-purpose wheel baseline: 67,351,552 bytes
  Native DLL reduction: 80.6%

Momento builds PyAV and a purpose-built shared FFmpeg runtime from pinned
sources. The runtime retains H.264 encoding through NVIDIA NVENC, AMD AMF,
Intel QuickSync, Media Foundation, and libx264; AAC audio; Matroska and MP4
muxing; and the filters and decoders used by recording and verification. It
does not ship the unrelated codec libraries present in PyAV's general-purpose
Windows wheel. Two clean builds produced byte-for-byte identical wheels.

The corresponding source bundle includes PyAV, FFmpeg, x264, NVIDIA codec
headers, AMD AMF headers, Intel oneVPL, and the exact GCC and winpthreads
runtime sources. Automated checks verified the encoder names, options,
fallback order, software encode, and H.264/AAC MKV and MP4 round trips. NVIDIA
has separate physical recording evidence; AMD and Intel hardware paths have
not been exercised on physical GPUs for this release.

the complete FFmpeg configure line embedded in Qt's DLLs and every
binary/source hash.

Corresponding source
--------------------

The GitHub release publishes both:

  Momento-0.2.5-source.zip
  Momento-0.2.5-third-party-source.zip

The installed SOURCE_OFFER.txt points to the exact release page and source
assets. Keeping the third-party archive as a separate release asset avoids
inflating the installer while providing matching source from the same download
location.

The third-party source bundle contains 17 hash-verified inputs covering the
Momento helper; the minimal PyAV runtime's PyAV, FFmpeg, x264, NVIDIA, AMD,
oneVPL, GCC, and winpthreads sources; PyQt/SIP; Qt
Base/SVG/Multimedia/Translations; and Qt Multimedia's FFmpeg and zlib inputs.
scripts/build_corresponding_source.py creates a deterministic ZIP and verifies
every embedded file after writing it.

Python release environment
--------------------------

The complete Python environment is pinned in constraints-release.txt and each
approved Windows wheel is locked by SHA-256 in requirements-release-hashed.txt.
The release wrapper recreates a dedicated virtual environment for every build,
installs only hash-approved wheels, and rejects missing, mismatched, duplicate,
or undeclared distributions before PyInstaller runs. Development packages are
not inherited from the working environment.

The installed licenses/Python directory contains every licence and notice file
supplied by every locked Python distribution, preserving source paths and
grouping files by canonical package name and exact version. Packaging fails if
any locked distribution lacks licence evidence. THIRD_PARTY_NOTICES.txt
identifies upstream projects and applicable terms.
